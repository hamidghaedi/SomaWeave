# Architecture

Case intake -> normalization -> technical evaluation -> provider-backed evidence retrieval -> evidence reconciliation -> interpretation -> reporting.

Scientific calculations are deterministic and separate from prose generation. Provider adapters translate external data to canonical evidence records, retaining raw source references. Optional analysis frameworks may be used behind stable interfaces; they do not determine the project directory layout.

The scaffold currently implements only input validation and CLI invocation. Future components are represented by reserved package directories; absence of implementation must not be mistaken for completed functionality.
